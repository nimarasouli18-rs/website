# 🌐 HTML & CSS Webpage

یک پروژه ساده برای تمرین و آشنایی با ساختار صفحات وب با استفاده از **HTML و CSS**.

در این پروژه یک صفحه وب ساده طراحی شده که شامل عنوان، توضیحات و اطلاعات تماس است.

## 📁 ساختار پروژه

```text
website/
├── index.html
├── style.css
└── README.md
```

## 🛠️ تکنولوژی‌های استفاده‌شده

* HTML5
* CSS3

## ✨ امکانات

* ساخت ساختار اصلی صفحه با HTML
* استفاده از Headingهای مختلف (`h1`، `h2`، `h3`)
* اتصال فایل CSS به HTML
* تنظیم رنگ پس‌زمینه با CSS
* طراحی ساده و مینیمال

## 🚀 نحوه اجرا

برای اجرای پروژه نیازی به نصب ابزار خاصی نیست.

فقط فایل زیر را با مرورگر باز کنید:

```text
index.html
```

یا از طریق ترمینال در محیط Linux:

```bash
xdg-open index.html
```

## 📸 محتوای صفحه

صفحه شامل موارد زیر است:

* عنوان اصلی: `Welcome to my webpage`
* توضیحات پروژه
* بخش اطلاعات تماس
