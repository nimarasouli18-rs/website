# 🌐 وب‌سایت شخصی و نمونه‌کار

یک وب‌سایت شخصی و ریسپانسیو برای معرفی خودم، مهارت‌های فنی، پروژه‌ها و مسیر یادگیری در حوزه **DevOps و مهندسی کامپیوتر**.

## 📌 درباره پروژه

این پروژه وب‌سایت شخصی من است که با هدف ایجاد یک حضور آنلاین حرفه‌ای و نمایش **مهارت‌ها، پروژه‌ها و تجربیات آموزشی** ساخته شده است.

تمرکز اصلی پروژه روی ساختاری ساده، تمیز و قابل استفاده در دستگاه‌های مختلف است.

## 🚀 اجرای پروژه

ابتدا Repository را Clone کنید:

```bash
git clone https://github.com/nimarasouli18-rs/website.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd website
```

در نهایت فایل `index.html` را با مرورگر باز کنید.

برای توسعه راحت‌تر نیز می‌توانید از افزونه **Live Server** در VS Code استفاده کنید.
